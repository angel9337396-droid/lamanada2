# INSTRUCCIONES DEL PROYECTO

## Archivo principal: `manada_domino`

**IMPORTANTE:** El archivo `manada_domino` es el archivo principal (INDEX) de esta aplicación.

Debes identificarlo, leerlo y analizarlo correctamente antes de realizar cualquier modificación.

### Reglas de trabajo
1. Reconoce `manada_domino` como el punto de entrada principal de la aplicación.
2. Analiza su estructura, funcionamiento y dependencias antes de modificar el código.
3. No crees otro archivo `index.html` ni reemplaces el archivo principal.
4. Todas las modificaciones relacionadas con la aplicación deben respetar la estructura existente.
5. Si necesitas agregar funcionalidades, intégralas correctamente con el archivo principal y sus archivos CSS y JavaScript correspondientes.
6. No elimines ni sobrescribas funcionalidades existentes sin necesidad.
7. Antes de realizar cambios, verifica cómo están organizados los archivos y las rutas del proyecto.

**Instrucción prioritaria:** Siempre que trabajes en este proyecto, toma `manada_domino` como el INDEX principal. No asumas que el punto de entrada es `index.html`.
